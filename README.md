# Blocklists

A simple blocklist aggregator that combines a wide variety of publicly available blocklist resources into a single, consolidated collection.

Maintaining blocklists from multiple sources can be tedious; This project automates the process by fetching blocklists from configured sources, verifying their compatibility with Pi-hole, and displaying them for your consumption.

### Disclaimer

The quality and behavior of the resulting blocklist depend on the upstream sources. Review the sources you include and test the generated list before deploying it in environments where false positives could cause problems.
